# 퀴즈런

10명 이상이 같은 문제를 동시에 풀고, 달리기 트랙에서 경쟁하는 수업 퀴즈 앱입니다.

## 사용 순서

1. 선생님 로그인 → 새 수업 만들기.
2. 문제 준비에서 PDF 텍스트 읽기 또는 수업 내용 붙여 넣기.
3. 문제 초안을 검토/수정하고 저장. 예시 문제로 먼저 시험할 수도 있습니다.
4. 대기실 열기 → 학생 초대 링크 복사 → Zoom 채팅에 직접 공유.
5. 학생은 링크에서 이름 입력 → 번호 확인 → 참여 확인.
6. 선생님이 첫 문제 시작 → 정답 공개 → 다음 문제 → 최종 결과.
7. 점수 기록에서 게임별 기록, 누적 순위, CSV 내보내기 확인.

같은 반은 같은 수업 링크를 계속 사용해야 기존 학생 번호와 점수가 연결됩니다. 학생이 이미 이름을 확정한 경우 다음 게임 대기실에서 '이번 게임 참여'를 누릅니다. 참여자 수를 10명으로 제한하지 않으며 전체 학생 명단과 완료 기록은 유지됩니다. 점수는 정답당 1,000점입니다. 레이스 순위는 정답 수가 많은 순이며, 같은 정답 수에서는 서버가 측정한 총 풀이 시간이 짧은 순입니다. 미제출 문제는 해당 문제의 마감까지 걸린 시간이 포함됩니다. 소수 인원으로 연습도 가능합니다.

## 구현 범위

- 초성/OX/객관식/주관식 편집과 서버 채점
- 1.2초 폴링으로 상태 동기화, 선생님 진행 제어, 서버 마감 시간
- 이름/번호 확정, 재접속, 날짜별 별도 기록과 누적점수
- 학생별 달리기 레인, 실시간 순위·풀이 시간, 전체 화면 보기, 모바일 대응
- PDF.js 브라우저 텍스트 추출과 자료 문장 기반 문제 초안

현재 문제 초안 생성은 규칙 기반이며 생성형 AI API는 연결하지 않았습니다. 초안은 선생님 검토가 필요합니다. 이미지 PDF의 OCR은 포함하지 않습니다. 동시 참여 30명의 등록·입장·답안 처리는 API 테스트로 검증했으며, 실제 30대 기기 동시 수업은 별도 검증이 필요합니다.

## 개발

Vinext/React + Cloudflare Workers/D1 + Sites. `npm install`, `npm run dev`, `npm run db:generate`. 개발/배포 시 Sites starter의 `scripts/`와 `worker/`를 유지합니다. D1 바인딩은 `DB`입니다. 실행 프로필, node_modules, 로컬 DB와 비밀값은 소스에 포함하지 않습니다.

검증: `node tests/classroom.test.mjs`, `npx tsc --noEmit`, Sites `build-site.mjs`.
