# 라이온즈 퀴즈런

10명 이상이 같은 문제를 동시에 풀고, 달리기 트랙에서 경쟁하는 수업 퀴즈 앱입니다.

## 사용 순서

1. 선생님 로그인 → 새 수업 만들기.
2. 문제 준비에서 **혼합 퀴즈** 또는 **초성퀴즈만** 선택 후 PDF 텍스트 읽기, 이미지 글자 읽기 또는 수업 내용 붙여 넣기.
3. 문제 초안을 검토/수정하고 저장. 예시 문제로 먼저 시험할 수도 있습니다.
4. 대기실 열기 → 표시된 6자리 PIN·QR코드·초대 링크 중 편한 방법으로 학생에게 안내.
5. 학생은 첫 화면에서 PIN 입력, QR 스캔 또는 링크 접속 → 이름 입력 → 번호 확인 → 참여 확인.
6. 대기실을 열기만 하면 게임은 시작되지 않습니다. 선생님이 **첫 문제 시작** → 정답 공개 → 다음 문제 → 최종 결과.
7. 점수 기록에서 게임별 기록, 누적 순위, CSV 내보내기 확인.

학생 번호는 수업별로 유지되며, 점수는 같은 선생님의 모든 수업에서 같은 이름으로 연결됩니다. 이름 비교는 유니코드·공백·영문 대소문자를 정규화합니다. 동명이인은 구분되는 이름을 사용하세요. 학생이 이미 이름을 확정한 경우 다음 게임 대기실에서 '이번 게임 참여'를 누릅니다. 참여자 수를 10명으로 제한하지 않으며 전체 학생 명단과 완료 기록은 유지됩니다. 점수는 정답당 1,000점입니다. 레이스 순위는 정답 수가 많은 순이며, 같은 정답 수에서는 서버가 측정한 총 풀이 시간이 짧은 순입니다. 미제출 문제는 해당 문제의 마감까지 걸린 시간이 포함됩니다. 소수 인원으로 연습도 가능합니다.

## 구현 범위

- 혼합 퀴즈(초성/OX/객관식/주관식)와 초성퀴즈만 모드 선택
- 모드별 작성 중 초안 유지, 초성 전용 예시·추가·생성, 저장한 모드로 게임 진행
- 초성/OX/객관식/주관식 편집과 서버 채점
- 1.2초 폴링으로 상태 동기화, 선생님 진행 제어, 서버 마감 시간
- 이름/번호 확정, 재접속, 날짜별 별도 기록과 월간 누적점수
- 학생별 달리기 레인, 실시간 순위·풀이 시간, 전체 화면 보기, 모바일 대응
- PDF.js 브라우저 텍스트 추출과 자료 문장 기반 문제 초안
- 사진·스크린샷 한글/영어 OCR(브라우저 Tesseract), 최대 10장 선택 및 인식 내용 검토
- 문제별 그림 첨부(브라우저에서 JPEG 축소 후 2MB 이하, R2 보관), 학생 문제 화면 표시
- 로컬 생성 QR과 6자리 PIN 입장, 기존 수업에도 PIN 발급 가능

현재 문제 초안 생성은 규칙 기반이며 생성형 AI API는 연결하지 않았습니다. 초안은 선생님 검토가 필요합니다. 이미지 PDF는 사진으로 저장해서 이미지 자료로 선택할 수 있습니다. OCR은 오인식할 수 있으므로 내용을 검토해야 합니다. 첫 사용 시 CDN에서 인식 엔진과 한글/영어 자료를 내려받습니다. 동시 참여 30명의 등록·입장·답안 처리는 API 테스트로 검증했으며, 실제 30대 기기 동시 수업은 별도 검증이 필요합니다.

## 개발

Vinext/React + Cloudflare Workers/D1 + Sites. `npm install`, `npm run dev`, `npm run db:generate`. 개발/배포 시 Sites starter의 `scripts/`와 `worker/`를 유지합니다. D1 바인딩은 `DB`, R2 바인딩은 `BUCKET`입니다. 실행 프로필, node_modules, 로컬 DB와 비밀값은 소스에 포함하지 않습니다.

검증: `node tests/classroom.test.mjs`, `npx tsc --noEmit`, Sites `build-site.mjs`.

인증, 요청 흐름, 기존 홈페이지 GitHub 토큰 처리: [AUTHENTICATION.md](AUTHENTICATION.md).

## 월간 리그와 학생 관리

이전 구현은 현재 수업의 history만 합산하여 새 수업에서 기존 점수가 누락되었습니다. 이제 수업 소유자별 모든 수업의 기존 기록을 읽어 이름으로 합산합니다. 기존 기록을 재작성하지 않고 예전 날짜 형식도 한국 시간으로 해석합니다.

월간 기준은 한국 시간의 달력 월입니다. 매월 1일 00시부터 자동으로 새 월간 합계가 시작되고 과거 경기 기록은 유지됩니다. 서버가 요청마다 월을 계산하므로 예약 작업 없이도 적용됩니다.

선생님 화면 → 점수 기록에서 개별·전체 월간 점수 리셋과 학생 개별·일괄 삭제를 사용할 수 있습니다. 리셋은 기록을 보존하고 집계 기준 시점만 갱신합니다. 삭제는 이 선생님의 모든 수업에서 학생 등록과 해당 점수 기록을 제거하고 기존 접속 토큰을 무효화합니다. 일괄 삭제는 전체 경기 기록도 비웁니다. 확인 창을 제공하며 다른 수업을 포함해 경기가 진행 중이면 관리 작업을 거부합니다.

최고 스피드왕은 현재 경기에서 모든 문제에 답한 학생의 총 풀이 시간순입니다. 정답 수를 함께 표시하고 정확도 우선인 점수 순위와 분리합니다. 미완주 또는 시간 정보가 없는 기록은 스피드왕에서 제외합니다.

출발·제출·정답·오답·마지막 3초·완주 및 박수 효과음은 Web Audio로 생성합니다. 첫 클릭 이후 재생되며 음소거 설정을 브라우저에 기억합니다.

디자인: 삼성 라이온즈 흰색/파랑 유니폼을 입은 창작 사자 캐릭터와 야구장 배경. 원본 생성 이미지에서 웹용 WebP를 만들어 public/assets에 포함했습니다.

검증: 30명 동시 처리 회귀 검사, 수업 간 점수 연결, 소유자 분리, 한국 시간 월 경계, 옛 기록 집계, 개별/전체 리셋·삭제와 재접속, 별도 스피드왕 순위.
